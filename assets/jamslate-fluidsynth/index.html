JamSlate and SongSlate: FluidSynth source and licences

Digital Slate Database · JamSlate · All apps

JamSlate and SongSlate play their band with FluidSynth 2.6.2, a free software synthesizer under the GNU Lesser General Public License, version 2.1 (LGPL-2.1). The copy inside the app has small changes. This page gives the complete source of the library as shipped in the app, the changes as a patch against the original, and how to replace it.

Downloads

  • fluidsynth-2.6.2-jamslate-source.tar.gz: the complete modified source, as built into the app (about 0.7 MB).
  • fluidsynth-2.6.2-jamslate.patch: only the changes, a unified diff against the original FluidSynth v2.6.2 (tag v2.6.2, commit c3b244ddfd094489a5490beee013c621a504adf2).
  • app-build-files/CMakeLists.txt and slate_synth.cpp: the build file and the small JNI wrapper that load FluidSynth in the app.
  • LGPL-2.1 licence text.
  • Original FluidSynth: github.com/FluidSynth/fluidsynth (tag v2.6.2).

What was changed

  • src/sfloader/fluid_sffile.c: when built with JAMSLATE_STB_VORBIS, the compressed samples of SF3 sound fonts are decoded with the built-in stb_vorbis decoder instead of libsndfile (which is not available on Android). The conversion to 16 bit follows the original libsndfile code path.
  • src/sfloader/stb_vorbis.c: added. stb_vorbis v1.25 by Sean Barrett, public domain (also available under the MIT licence, see the end of the file).
  • doc/CMakeLists.txt and test/CMakeLists.txt: replaced by empty stubs, because the documentation and test programs are not built for Android.
  • The gcem folder holds the upstream gcem library (Apache-2.0), unchanged. Everything else is the original FluidSynth.

How the library is used, and how to replace it

FluidSynth is built as its own shared library, libfluidsynth.so, separate from the app's code, and the app loads it at run time (System.loadLibrary("fluidsynth"), in the shared synth module of both apps). You can therefore build a modified version and use it with the app:

  1. Unpack the source, and build it for Android with the NDK using app-build-files/CMakeLists.txt as the starting point (it turns off every audio driver and sets JAMSLATE_STB_VORBIS; the output name must be libfluidsynth.so).
  2. Take the app's APK, replace lib/<abi>/libfluidsynth.so with your build, and sign the APK with your own key. The app's own code does not need to change: it only calls the public FluidSynth C interface.

If you need help with this, write to gameslate@proton.me.
